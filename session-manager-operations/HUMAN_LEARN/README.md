# HUMAN_LEARN/

Human-readable explainer pages, written by the `session-manager-dev:explain-to-me`
skill. **Not an OWNERS namespace** — no code path writes here, no `assertOpsWrite`
guard applies; it's regenerated by re-running the skill, not by the app.

**Retention: keep.** Regenerate in place rather than deleting; there is no archive
subfolder.

## Contents

- `index.html` — one combined component-explainer page. Last regenerated **2026-07-24**.
  It is now **stale** on the removed Browser tab, DOM-capture, and Web Remote (desktop
  half) surfaces — those sections describe subsystems that have since been removed from
  the codebase. Don't trust it for those areas; treat it as history until regenerated.
- `SKILL_MAP.html` — **never produced.** The `explain-to-me` skill's own description and
  `tests/unit/pluginSkillEdges.spec.ts` both name it as the skill-chain map companion
  page, but no such file has ever been written here.

## How to update

Run `/explain-to-me` to regenerate `index.html` for a given topic/component, or to
produce the missing `SKILL_MAP.html`. Don't hand-edit the HTML — it's meant to be
regenerated from the live codebase, not patched.
