Session Manager

Executive overview — what it is and its top features, briefly.

An Electron desktop app that acts as a local cockpit for the Claude Code CLI: a terminal you actually work in, plus 25+ tabs for configuration, observability, and scheduling around that terminal. A companion mobile web cockpit mirrors session state from the desktop app.

Terminal sessions

Each open tab is a real PTY running claude, managed by a per-tab PtyManager. The tab ID doubles as the Claude session UUID, so it passes straight through to --session-id and to transcript lookup — no separate ID mapping.

Scheduler — unattended PRD execution

Runs written task specs ("PRDs") as headless claude -p jobs, on a schedule or when API usage frees up. Policies: manual, on-reset, or when-available (default), which polls billing usage every minute to decide when to start/stop jobs around the 5-hour usage window. Concurrency is capped at 3 simultaneous jobs to avoid overloading the machine. A boot-time reconciler reaps jobs orphaned by a crash, and a periodic supervisor probe kills stuck poll-loops without killing the agent itself.

Voice

Hands-free dictation into the terminal: local voice-activity detection decides when you're speaking, transcription runs locally via Whisper, and a countdown auto-submits your utterance unless you keep talking.

Configuration & observability tabs

One left-nav entry per concern: Settings, Permissions, Skills, Plugins, MCP Servers, Hooks, Subagents, Projects, Keybindings, System Prompt, Repo Viz, Search. Each follows one of two shared UI shapes — a scoped JSON editor (Settings) or a list-plus-detail view (Skills) — so new tabs stay consistent without reinventing layout.

Memory Clusters

Reads a project's saved workspace memories and, on request, groups them into named semantic clusters with cross-links — a browsable map of what the agent has remembered about the project.

Usage & History

Usage shows live billing/rate-limit standing pulled from Anthropic's usage endpoint. History is analytics over past sessions — cost and activity charts, not a session browser or resume point.

Web Remote (mobile)

A same-origin relay lets a paired phone browser watch and lightly steer an active desktop session — session state, summaries, and gated remote-control actions — with the desktop app remaining the source of truth.

src/main/webRemote.cjs

Admin API & MCP integration

A loopback-only, token-authed HTTP API exposes a narrow scheduler-control surface (list jobs, reset a stuck one), wrapped as MCP tools so an agent — or this very app — can manage the job queue directly.
