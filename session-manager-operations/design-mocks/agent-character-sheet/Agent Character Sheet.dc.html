Every agent is a character. Gear is what it carries.

Personality and stats already live in the persona file. This adds gear — built-in tools, MCP servers, packs — equipped by drag-and-drop or the keyboard, and a separate Constraints panel for the rules on that gear. Every slot writes a key the persona already has: tools · mcpServers · packs · environment.
