WHY IT FEELS SCRUNCHY — FOUND IN THE CODE
Settings stacks 7 strips before the first setting: tabs, Epic note, Epic toggle, sub-tabs, scope note, filter bar, file chip, then summaries.
Memory puts a second page header ("CONFIGURE Memory") under the page header, then lists 9 subagent scopes that are all "off".
The 5 tabs are 22px tall at 12px. Almost every label is 10–12px, so nothing stands out.
Two bugs the redesigns fix: folder chips say "created on first save" for folders that exist (SourceChip reads a folder as a file), and the skill toggle's knob sits outside its track.
SHARED BY ALL THREE
The tab switcher is the overview. Each file shows its live status: count, health, age. A missing CLAUDE.md is visible from every tab.
One file bar per tab holds the real path, the scope and what it means, and the one primary action. It replaces the note strips.
One header per page. Type grows from 11 to 15 to 22–46px, controls are 36–40px tall, and color appears only where something needs you.
Built with the app's own Almanac tokens (Geist, Newsreader, IBM Plex Mono, terracotta on paper), the same warm-paper look as the attached system.
THE THREE DIRECTIONS
1a Folder tabs. The safest option: today's layouts, cleaned up. Tabs become file cards attached to one panel.
1b Ledger. Editorial: a masthead of big numbers, then tables and grids instead of side rails. Settings show which scope each value comes from.
1c Workbench. The boldest: a dark command band, and every tab uses the same rail + detail layout with the file shown top-left. Code views are dark.
