You are auditing and refreshing CLAUDE.md files in this repository. CLAUDE.md is the per-project instruction file Claude reads on every conversation — it must be accurate, concise, and scoped to where it lives.

Step 1 — Inventory

Find every CLAUDE.md in the repo:

find . -name "CLAUDE.md" -not -path "*/node_modules/*" -not -path "*/.git/*"

For each one, note:

  • Path and line count
  • Last commit touching it: git log -1 --format="%ar — %s" -- <path>
  • Subtree it governs (project root, a package, a service, etc.)

Step 2 — Detect drift

For each CLAUDE.md, sample what changed in its subtree since the file was last touched:

git log --oneline --since="<last-CLAUDE.md-commit-date>" -- <subtree>
