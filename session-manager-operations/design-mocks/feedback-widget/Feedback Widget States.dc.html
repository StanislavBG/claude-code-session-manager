1Floating feedback widget — key states and variations
Feedback widget · state board

One small launcher, then everything floats over the page.

At rest it's a single launcher. Click it or press ⇧F and the visible page is captured: a thin rust frame shows you're marking up a screenshot, and the tools and panel float on top. The host page never moves, shrinks or reflows.

Open the clickable prototype → Use Tweaks to switch flow, launcher, toolbar, success style, and to make the server fail.

What your server receives
POST {your endpoint} multipart screenshot.png viewport, marks drawn in report.json { type, title, details, marks: [{ n, kind, x, y, w, h, selector?, note? }], page: { url, viewport }, console: [...], network: [...], user: { id, name, email } }
Assumed: widget renders in a Shadow DOM root (no CSS leaks either way) and hides itself from the screenshot.

Launcher

What sits on the site all day. Shown 1:1, at rest and on hover.

1aCorner bubble. Familiar. Expands to show the ⇧F shortcut on hover.
1bEdge tab. Never covers content; slides out on hover.
1cMini pill. Smallest footprint, paper-toned so it fades into the page.
1dShortcut only. No visible button. A one-time hint teaches ⇧F, then nothing is on the page.

Flow and panel layout

Three ways to combine marking and describing. Every panel floats with margins and a shadow.

1eMark up, then describe. Mark up the whole page first, then a floating card collects the words. Marks stay visible behind it.

Markup toolbar

All six tools: pin, element, box, arrow, draw, text. Every toolbar has a drag handle so it can be moved off whatever it covers.

1hFloating dock, top center. Shown with a pin's comment open.
1iVertical rail, left. Shown with the element picker hovering the Search button.
1jCorner toolbar. Opens where the launcher was, so the click feels like the button unfolding.

Submit and after

Sending, three success styles, failure, and the guard against losing work.

1kSending. Progress bar in the panel; fields lock.
1lReceipt. Ticket ID plus exactly what was sent.
1mToast. Closes right away; Undo for 6 seconds.
1nFold into launcher. The panel shrinks into the button, which turns green for a moment.
1oServer error. Draft kept in the browser; Retry.
1pDiscard guard. Esc or close with marks or text asks first.
