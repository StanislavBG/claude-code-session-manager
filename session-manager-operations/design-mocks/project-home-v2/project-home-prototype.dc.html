Claude Code Session Manager

A local Electron cockpit for the Claude Code CLI: multi-tab terminal, full configuration surface, scheduler, voice dictation and live observability in one window.

v0.127.0 MIT Electron 42 React 18 + Vite npm: claude-code-session-manager

WHO IT’S FOR

People who already use the claude CLI and want to run several sessions at once, edit every config file Claude Code reads, queue overnight work as PRDs, dictate by voice, and watch transcripts live. Described in the README as a single-author project; free and open-core (the app and its Field Manual stay free).

KEY FEATURES

Dormant tabs + chat box

New tabs start as a chat box with no PTY and no claude process until the first message; the headless chat runner uses claude -p with stream-json and session resume. Hydrate to a full terminal any time.

Scheduler / PRD queue

PRDs under the scheduler’s epics folder run as headless claude -p jobs, authored through the scheduler_create_prd MCP tool. Includes a queue-health linter.

Epics (Sessions)

One Epic = one unit of work = one claude session, run in its own git worktree. Created from an Agent (who) plus a Tag (what); the opening prompt is composed as Actor, Input, Mission.

Config surface

Hooks (all 29 events with a test-fire runner), plugins, MCP servers (five transports), skills, permissions, settings with 4-scope drift display, and a Memory tab.

Voice

Local Moonshine ASR and Silero VAD: push-to-talk, continuous listening, auto-submit, barge-in. Nothing leaves the machine.

Command palette + modes

Cmd/Ctrl-K palette with banded commands; --simple launches a single-terminal, chrome-free cockpit. Toasts surface non-fatal errors.

How it works

One Electron window over the claude CLI. The main process owns processes, files and background jobs; the React renderer draws the cockpit; macros and the scheduler run work as Epics.

THE PIECES

src/mainMain processPTYs, files, IPC, and the writer routes that own generated artifacts.
src/rendererRendererThe React 18 + Vite cockpit: tabs, Project Home, Scheduler, Memory.

FAQ

What newcomers ask first — each answer sourced from the project’s own docs.

Does my voice leave the machine?No. Speech is transcribed on your own machine. The model loads on your first press and unloads after half an hour without voice.Source · manual/chapters/cockpit-tour.html › Voice input
How do I turn telemetry off?Flip the toggle in Settings, or set SM_TELEMETRY=0 when running from a script or scheduled job — it overrides everything else.Source · manual/chapters/cockpit-tour.html › Anonymous telemetry
Can I drive it from my phone?Yes. Turn on remote control under Settings › Phone remote, pair each computer once, then switch between them from the web app header.Source · manual/chapters/cockpit-tour.html › The web remote
I just want one terminal.Launch with --simple and Session Manager boots straight into a single terminal, with no navigation or tabs around it.Source · manual/chapters/cockpit-tour.html › Simple mode
