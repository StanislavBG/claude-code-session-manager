Glossary — every term in plain English

Every word this manual uses, explained in a sentence or two, with a pointer to where it is covered.

Active
A Session that is running: it is doing the work and reporting back to you. See: Your first Session — from idea to working agent
Agent
The member of your agency who works a Session — the "who" behind the job. See: Shaping your team — Agents, Missions and one-click Actions
Agent Library
The place where you browse, edit, and create the agent personas on your machine. See: Shaping your team — Agents, Missions and one-click Actions
AI agent
Not a chatbot that just answers. It is a program that plans, uses tools, and does multi-step work toward a goal you give it. See: What is an AI agent?
Approve & start
The button that turns a Proposed Session into an Active one and sends its first instruction. See: Your first Session — from idea to working agent
Architect
Your agency's project lead. It plans the work, breaks it into pieces, and tracks it to done. See: Meet your agency — the team that works for you
Chat
The conversation view of a Session, where you type a message and read the reply. See: Your first Session — from idea to working agent
Claude Code
The command-line tool from Anthropic that Session Manager wraps in a cockpit. See: Claude Code in plain English
Completed
A finished Session, archived with its full history. See: Your first Session — from idea to working agent
Dashboard
The one-page overview of every project and every Session on your machine. See: Around the cockpit — Home, memory, usage, history and more
Dev-lead
One of your agency's builders. It takes a single, already-scoped piece of work and builds exactly that. See: Meet your agency — the team that works for you
File Explorer
The built-in file browser and editor. See: Around the cockpit — Home, memory, usage, history and more
History
A record of past Sessions, with cost and usage over time. See: Around the cockpit — Home, memory, usage, history and more
Hooks
Small scripts that run automatically when something happens in a Session. See: New abilities — skills, plugins, tools and hooks
Host on Bilko.run
The feature that publishes a project's overview page to the public web. See: Around the cockpit — Home, memory, usage, history and more
House rules
This manual's word for the standing instructions, settings, and permissions you give every Session. See: House rules — instructions, settings and permissions
MCP Servers
Connections that let an agent reach outside tools and services. See: New abilities — skills, plugins, tools and hooks
Memory
Notes an agent keeps and can read back in a later Session. See: Around the cockpit — Home, memory, usage, history and more
Mission
What kind of work a Session is — the "how." It shapes how eagerly your agency queues follow-up work. See: Shaping your team — Agents, Missions and one-click Actions
Needs review
A work order that stopped because it has a question only you can answer. See: Trust, but verify — how the work gets checked
New Session
The button that starts a fresh Session. See: Your first Session — from idea to working agent
Permissions
The rules that decide what an agent may do without stopping to ask you first. See: House rules — instructions, settings and permissions
Plugins
Installable extensions that add new skills, agents, or tools to Claude Code. See: New abilities — skills, plugins, tools and hooks
Project Home
A one-page, auto-written overview of a single project. See: Around the cockpit — Home, memory, usage, history and more
Proposed
A Session that has been set up but has not started yet. Nothing has run, and nothing has been spent. See: Your first Session — from idea to working agent
Queue
The list of work orders that are waiting, running, or finished. See: Work that runs while you're away — plans and the Scheduler
Scheduler
Your agency's work calendar. It lines up work orders and runs them, even while you're away. See: Work that runs while you're away — plans and the Scheduler
Session
One job you hand to your agency, from a goal to a finished result. Chat and Terminal are two ways of looking at the same Session. In the code, a Session is called an Epic — you will not see that word in the app itself. See: Your first Session — from idea to working agent
Session Manager
This app: a desktop cockpit for running several Claude Code agents at once. See: Welcome — your friendly map of what's ahead
Settings
App-wide preferences, such as theme, voice, and other machine-level choices. See: House rules — instructions, settings and permissions
Skills
Packaged instructions an agent can load for a specific kind of task. See: New abilities — skills, plugins, tools and hooks
System Prompt
The house rules every Session reads before anything else — your standing instructions file. See: House rules — instructions, settings and permissions
Tag Library
The place where you manage the list of Missions a Session can carry. See: Shaping your team — Agents, Missions and one-click Actions
Terminal
The raw command-line view of a Session, for when you want to see everything it is doing. See: Your first Session — from idea to working agent
Validator
Your agency's quality control. It checks finished work against what was promised. See: Meet your agency — the team that works for you
Voice
Talk to your agents with your microphone instead of typing. See: Around the cockpit — Home, memory, usage, history and more
Work order (PRD)
One scheduled piece of work the Scheduler runs on its own, with everything it needs to finish written down. See: Work that runs while you're away — plans and the Scheduler
