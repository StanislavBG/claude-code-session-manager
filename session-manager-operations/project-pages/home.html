claude-code-session-manager

Local cockpit for the Claude Code CLI — an Electron desktop app.

v0.89.0MITLinux & macOSElectron 42 · React 18 · Vite

What it is

Wraps the claude CLI in one desktop window: a multi-tab terminal, a configuration surface for the files Claude Code reads, a scheduler that runs queued PRDs as headless claude -p jobs, local voice dictation, and live transcript observability. New tabs open as a lightweight chat box and stay dormant (no PTY, no claude process) until the first message is sent.

Who it is for

People who already use the claude CLI and want to run several sessions at once, edit its config in a UI, queue overnight work, and dictate with a microphone. The README describes it as a single-author hobby project with anonymous, opt-out telemetry (SM_TELEMETRY=0).

Key features

Dormant tabs + chat
Headless chat engine over claude -p stream-json with resume; hydrate to a terminal on demand. --simple gives a single-terminal mode.
Scheduler / PRD queue
PRDs under session-manager-operations/scheduler/epics/<epic-id>/prds/ become headless jobs; authored via the scheduler_create_prd MCP tool.
Config surface
Hooks (29 events, test-fire runner), plugins, MCP servers (5 transports), memory, settings with 4-scope drift display.
Voice
Local Whisper ASR plus Silero VAD in a Web Worker; push-to-talk, continuous listening, barge-in. Nothing leaves the machine.
Command palette
Cmd-K, grouped into session, voice, scheduler, config and nav bands.

Domain model

  • TAB = cwd = Main Project — one tab per project.
  • EPIC — one unit of work (user-facing name "Sessions"), 1:1 with a claude session, run in its own git worktree (sm-epic/<id>).
  • Epics are created by an actor (agentType) and a mission (tag); every Epic is born proposed, and only a human pressing New Epic mints one.
  • Per-project state lives under <cwd>/session-manager-operations/, each namespace with a single owning writer.

Run it

# end users
npx claude-code-session-manager@latest
npx claude-code-session-manager@latest --simple   # single terminal

# from a checkout
npm install
npm run dev      # Vite + Electron with HMR

First launch downloads Electron (~200 MB) and rebuilds node-pty.

Project laws worth knowing

  • The app is free and open-core; the Field Manual is the only paid artifact.
  • No CommonJS in the renderer, no ES modules in main.
  • Every claude -p call site must pin --model and acquire a slot from lib/sessionSlots.cjs.
  • Full rules: CLAUDE.md and session-manager-operations/architecture/.
