# Scheduler deletion audit — `src/main/scheduler.cjs`

- **Audited commit:** `c429638ad17e557023bc9a4e1aafd44f702a4ac3` (HEAD of the job worktree, 2026-10-22). File is 11,283 lines, 153 top-level functions.
- **Line numbers** are at that SHA; sibling PRDs (refire cap, `runVerify.cjs`) will shift them. Re-grep the symbol before editing.
- **Method:** (1) every top-level `function` / `const x = (` listed and grepped with `grep -rnw <name> src scripts` — 19 have exactly one in-file reference and no outside caller, but all 19 are real single-use helpers (see Rejected). (2) Every `process.env.*` in the file grepped across `src scripts tests package.json CLAUDE.md architecture/` for a setter. (3) Every `module.exports` name grepped for production callers. (4) Retired mechanisms taken from `CLAUDE.md` (flat `scheduler/prds/` RETIRED; `parallelGroup` never a barrier) and `queueStore.cjs`.
- **Honest headline:** the file has almost no *dead functions*. The 11k lines are live code that grew by accretion, so the realistic deletions are small (~230 lines total here, ~300 counting `queueStore.cjs`). The bigger win is *extraction* (`registerScheduleHandlers` 372 lines, `init` 270, `registerAdminRoutes` 198 → `src/main/lib/scheduler/`), which is a move, not a deletion, and is listed under Rejected so the planner can queue it separately.
- Line counts are estimates (±5). "Kill switch nobody sets" = no setter found in repo scripts, tests, docs, `package.json`; a user could still export it in a shell, which is the residual risk.

## Rejected (checked, not deletable)

- **19 single-reference helpers** (`getAvailableMemMb`, `biasJobOomScore`, `recheckPrdSourceForJob`, `maybeAutoRequestRestart`, `mutateBody`, `pathExistsInTree`, `isRunCancelled`, `tickWatchdogMs`, `bootRowPid`, `signalAdoptedGroup`, `spawnJobStillFinalizing`, `toCompactPrdEntry`, `clearFireTimer`, `computeFireAt`, …): one call site each, but each is called (grep shows the call) — single-use extraction, not dead. (`clearFireTimer`/`computeFireAt` are folded into #2.)
- **`registerScheduleHandlers` (9576, ~372 lines), `registerAdminRoutes` (11087, ~198), `init` (10185, ~270):** live (called from `index.cjs:1001` / admin server). Candidates for *extraction* into `lib/scheduler/`, not deletion.
- **`allocateParallelGroup` wrapper (1289, 56 lines):** looks like a duplicate of `prdParser.allocateParallelGroup`, but it adds the cross-Epic + archive `extraFloor` (PRD 832 unique-number law); `parallelGroup` itself is a display/number hint still written to PRD filenames and `resolveFixPlanPath` (3068), so not removable.
- **Flat-PRD sweep (`lastFlatSweepMs`, 1436, 1462–1475, `flatSweepThrottle.cjs`):** flat `scheduler/prds/` is RETIRED, but the sweep is the mechanism that cleans stragglers (CLAUDE.md: "auto-consolidated … on every `reconcile()` pass") and is already throttled. Deleting it needs a telemetry proof no install still drops flat files; defer.
- **`legacy-adopted` stamp / `ipc:schedule:adopt-prd` (9750–9765):** live IPC wired in `preload/index.cjs:318` and the quarantined-PRD adopt UI.
- **`SM_AUTOFIX_DISABLE`, `SM_TICK_WATCHDOG_MS`, `SM_BASELINE_GATE_AUTHORITY_DISABLE`, `SM_GATE_AUTHORITATIVE_DISABLE`, `SM_SUPERVISOR_DISABLE`:** set by 7+ unit/e2e tests or documented operator kill switches in `scheduler-operations.md` / `tests/README.md`.
- **`runGateShadow` / gate-shadow machinery (8900–9100, 9235–9275):** named "shadow" but it is the authoritative gate runner for rung 5 (`scheduler-operations.md:163–174`).
- **`notifyNeedsReview` tail callers `flushDueReviewNotices`/`reviewNotice.cjs`:** the live quiet-by-default path; only the immediate branch dies (#1).
- **60 exports with no production caller (`guardedTick`, `buildFinishProtocol`, `computeDegradedBudget`, …):** exported for tests only, but each is used internally (in-file count ≥2), except the deliberate test seams `_mutateForTests` and `awaitGateShadowIdle`. Removing the export line saves 1 line each and breaks the tests' import seam; not worth a PRD.
- **`SM_DEV` / `SM_AUTO_UPGRADE_RESTART` gating in `maybeAutoRequestRestart`:** SM_DEV is set by `npm run dev`; function is live (driven from `driveUpgradeDrain`).
